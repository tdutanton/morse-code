# Морзе / Русский алфавит

Нативный прототип приложения для Windows на WPF и .NET 10. Приложение помогает учить азбуку Морзе для русского алфавита и цифр.

## Запуск

Требуется Windows и .NET 10 SDK или Desktop Runtime:

```powershell
dotnet run --project src/MorseCode/MorseCode.csproj
```

Для запуска собранного приложения:

```powershell
dotnet publish src/MorseCode/MorseCode.csproj -c Release -r win-x64 --self-contained false
```

Готовый файл появится в `src/MorseCode/bin/Release/net10.0-windows/win-x64/publish/MorseCode.exe`.

## Возможности прототипа

- справочник 33 русских букв и 10 цифр;
- отображение кода точками и тире;
- воспроизведение сигнала с регулируемой скоростью;
- тренировка «на слух» и ввод кода Морзе по символу;
- счёт правильных ответов и подсказка после проверки.

Е и Ё имеют одинаковый сигнал; в проверке на слух принимаются обе буквы.
Кнопка «Показать ответ» считается пропуском и увеличивает число попыток.
Смена набора или режима сбрасывает счёт. Прогресс между запусками пока не сохраняется.
Скорость задаёт длительность точки по формуле `1200 / WPM` мс; тон 650 Гц.

## Проверки

```powershell
dotnet run --project tests/MorseCode.Checks/MorseCode.Checks.csproj
```

Проверяются состав алфавита, обработка ответов и длительности/заголовки WAV.
